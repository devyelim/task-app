## Task Manager – MVC & CRUD Example

Projeto desenvolvido para demonstrar conceitos de MVC e CRUD
utilizando Laravel.

### Funcionalidades
- CRUD completo de tarefas
- Relacionamento com usuário
- Validação com Form Requests
- Organização MVC
- Filtros por status

### Conceitos aplicados
- MVC (Model, View, Controller)
- RESTful Routes
- Eloquent ORM
- Blade Templates
